Create your administrator account

First installation only. Create the account that will manage user approvals and audit logs.

The one-time setup key is generated on the server during first startup. Ask the server owner for it; it is not a regular user password.

Use at least 10 characters. There is no default password.

Find CROSSMATCH_SETUP_KEY in the server’s local .env file. Keep it private. Setup is disabled once the first administrator is created.
